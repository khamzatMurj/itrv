# ITRV Multi-Module Repository Implementation Plan

**Goal:** Combine the three committed Spring Boot services into one publishable Gradle multi-project repository.

**Architecture:** A new root project owns Gradle settings and the wrapper. Gateway, customer, and inventory remain independently buildable application modules beneath the root.

**Constraints:**
- Preserve the existing three repositories unchanged.
- Exclude generated files and nested repository metadata.
- Do not run tests; verify project discovery and assembly only.
- Publish exactly to `https://github.com/khamzatMurj/itrv.git` on `main`.

**Acceptance Signals:**
- `./gradlew projects` reports all three modules.
- `./gradlew assemble -x test` exits successfully.
- Local and remote `main` resolve to the same commit.

## Chunk 1: Assemble and Publish

### Task 1: Create the aggregate skeleton

**Files**
- Create: `README.md`
- Create: `settings.gradle.kts`
- Create: `.gitignore`
- Copy: `gradlew`, `gradlew.bat`, and `gradle/wrapper/`

**Step 1: Create root metadata**
- Set the README heading to `itrv`.
- Include the three module paths in Gradle settings.

**Step 2: Verify the skeleton**
- Command: `./gradlew projects`
- Expected: all three module names appear after module integration.

### Task 2: Integrate the three service modules

**Files**
- Create: `gateway-service/build.gradle.kts` and `gateway-service/src/`
- Create: `customer-service/build.gradle.kts` and `customer-service/src/`
- Create: `inventory-service/build.gradle` and `inventory-service/src/`

**Step 1: Copy committed service snapshots**
- Copy build files and source trees from the three clean service repositories.
- Do not copy nested Git metadata, build output, IDE files, wrappers, or settings files.

**Step 2: Verify module discovery**
- Command: `./gradlew projects`
- Expected: `:gateway-service`, `:customer-service`, and `:inventory-service` are listed.

**Step 3: Verify the aggregate assembly**
- Command: `./gradlew assemble -x test`
- Expected: `BUILD SUCCESSFUL`.

### Task 3: Create and publish the initial commit

**Files**
- Create: `.git/` repository metadata

**Step 1: Initialize and commit**
- Initialize Git with branch `main`.
- Stage the complete aggregate repository.
- Commit with subject `first commit` using the repository commit workflow.

**Step 2: Configure publication**
- Add `https://github.com/khamzatMurj/itrv.git` as `origin`.
- Push local `main` to remote `main` as explicitly requested.

**Step 3: Verify publication**
- Confirm the working tree is clean.
- Compare local `HEAD` with `refs/heads/main` from `origin`.
- Expected: both hashes match.
